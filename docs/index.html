How the scores work

Scores come from hand-written rules, not yet learned from flights or calibrated. Each rule scores 0-100% smoothly and the day's score is set by the weakest rule. Good is 65% or more, marginal 35-64%, poor under 35%. Thermal strength is an estimate from sunshine and boundary-layer depth. The hourly strip shows the XC score for each hour.
